## 7. Архитектура (Windows MVP)

### 7.1 Структура репозитория (предложение)

```
audiophantom/
  CLAUDE.md
  docs/                      # PLAN, TARIFFS, FEATURES_INFO, REACTIONS, ARCHITECTURE, PRIVACY_LEGAL, ECONOMICS, ROADMAP, OPEN_QUESTIONS
  apps/desktop/              # Electron + TypeScript (Vite, React для панели)
    src/main/                # окна, трей, IPC, горячие клавиши, аудио-пайплайн
    src/preload/
    src/renderer/panel/      # панель (положение настраивается)
    src/renderer/overlay/    # прозрачный click-through оверлей курсора
    native/                  # сайдкары (Windows UI Automation, WASAPI loopback при необходимости)
  packages/core/             # провайдеры STT/LLM/TTS/embeddings, триггеры, ретривер, пайплайн реакции
  packages/plans/            # plans.ts, features-info.ts (единый источник истины тарифов)
  services/api/              # Supabase Edge Functions: прокси к провайдерам, метеринг, лимиты, вебхуки Paddle
  supabase/migrations/
  eval/                      # записи звонков (EN/RU/RO), эвал-харнесс
```

### 7.2 Стек

- **Desktop:** Electron + TypeScript; интерфейс панели — React; `better-sqlite3` + `sqlite-vec` + FTS5 (локальный индекс); `onnxruntime-node` для Silero VAD.
- **Захват звука:** два канала — **микрофон = «я»**, **системный звук (loopback) = «они»**; разделение по каналам бесплатное и надёжное. Сначала пробуем встроенный loopback Electron (Windows); ⚠ проверить; запасной вариант — маленький нативный сайдкар на WASAPI loopback.
- **VAD:** Silero VAD (локально).
- **STT (интерфейс-провайдер):**
  - локальный Whisper (whisper.cpp / faster-whisper) — режим «Eco» и разработка;
  - **Groq Whisper Large v3 Turbo** — стандарт в облаке (≈ $0.04/час; минимум биллинга 10 с на запрос → резать по VAD-сегментам, не слать мелочь);
  - **Deepgram Nova-3 streaming** — «премиум-часы» (≈ $0.29–0.46/час; стриминг с задержкой <300 мс).
- **LLM (интерфейс-провайдер):** карточки и классификатор — самая дешёвая модель (класса Gemini Flash-Lite); резюме, бриф, ассистент, vision-указание — средняя (класса Gemini 3.6 Flash). Возможна замена на Groq-LLM или локальный Ollama (Qwen) для разработки. ⚠ Качество Flash-Lite для карточек проверить на эвале.
- **Embeddings:** локально через Ollama (bge-m3 или multilingual-e5) → SQLite (`sqlite-vec`) + BM25 (FTS5); гибридный поиск (смысл + точные слова/цифры).
- **TTS:** встроенный Windows TTS (бесплатно); позже Piper/Kokoro; облачный вариант (Groq Orpheus ≈ $22 за 1 млн символов) опционально.
- **Backend:** Supabase (Auth, Postgres+RLS, Edge Functions, cron). Для разработки хватает бесплатного тарифа (500 МБ БД, 50k MAU, 5 ГБ трафика); продакшен — Pro $25/мес (8 ГБ БД, 100 ГБ файлов, 250 ГБ трафика, 100k MAU).
- **Платежи:** Paddle (Merchant of Record), вебхуки → Supabase (раздел 10).
- **Хранение токенов на клиенте:** Electron `safeStorage`/Windows Credential Manager.

### 7.3 Пайплайн звонка

```
mic(me) ─┐
         ├─> VAD ─> STT ─> транскрипт (я/они, с таймстемпами)
loopback ┘                         │
                                   ▼
        префильтр (маркеры вопроса / глаголы-просьбы / имя)
                                   ▼
        классификатор (дешёвая LLM) → {is_question, is_screen_action, addressed_to_me, topic}
                                   ▼
        гибридный поиск (локальные документы + проиндексированные интеграции)
                                   ▼
   L1 карточка ─► (пауза+высокая уверенность) L2 шёпот ─► (подтверждение) L3 скриншот+шаги
                                   ▼
   после звонка: резюме, обещания, заметки по приложениям, глоссарий-история → облако (текст)
```

### 7.4 Окна

- **Панель:** окно «поверх всех», перетаскиваемое, размер меняется, положение/угол настраивается; прозрачность; режим click-through когда не нужна.
- **Оверлей курсора:** прозрачное полноэкранное окно на каждом мониторе, click-through, рисует пульс/стрелку и номер шага.
- **Скрытие от демонстрации:** оба окна с `setContentProtection(true)` (на Windows использует флаг исключения окна из захвата; ⚠ работает с Windows 10 версии 2004+, на старых — чёрный прямоугольник; проверить в прототипе).

### 7.5 Локальные данные

SQLite на устройстве: индекс документов и интеграций (чанки, эмбеддинги, FTS), локальные буферы звонка (последние минуты), настройки, заметки по приложениям (кэш). Индекс **не** синхронизируется в облако на MVP (⚠ решение для MVP; каждое устройство индексирует само).

### 7.6 Секреты и прокси

Клиент **не** хранит ключи STT/LLM. Все платные вызовы идут через серверный прокси (Supabase Edge Functions или Cloudflare Worker): аутентификация пользователя → проверка тарифа и лимитов → вызов провайдера → учёт расхода. Для личной разработки допускается `.env` с бесплатными ключами **только локально**, вне git.

### 7.7 Указание курсором: формат

Модель возвращает структурированный JSON, не теги в тексте:

```json
{ "steps": [ { "n": 1, "label": "Registration page", "display": 0, "x": 0.31, "y": 0.18, "w": 0.1, "h": 0.04, "confidence": 0.82, "hint": "..." } ],
  "detail_text": "…подробное объяснение для панели…" }
```

Координаты нормализованы относительно скриншота; маппинг в физические пиксели с учётом DPI и нескольких мониторов. Шаг сменяется, когда замечен клик/смена экрана, по команде «дальше» или клавише. **Ultra:** добавляем Windows UI Automation (дерево доступности: названия и границы элементов) + локальный OCR как более точный и дешёвый источник; для canvas-приложений (Figma) — откат на vision или текстовые шаги.

### 7.8 Модель данных (черновик, Supabase Postgres, RLS по `user_id`)

`profiles` (plan, trial_started_at, trial_seconds_used, paddle_customer_id), `subscriptions`, `usage_counters` (период; live_seconds_standard, live_seconds_premium, assistant_requests, agent_tasks), `devices`, `settings` (положение панели, режим, имена/прозвища, горячие клавиши, язык), `calls` (id, started_at, title, platform, language, saved), `call_summaries` (text, expires_at), `transcripts` (segments jsonb, expires_at), `promises` (call_id, text, owner, due, status; **не удаляются по retention, пока open**), `app_notes` (app_id, notes), `knowledge_packs` + `knowledge_pack_members`, `deletion_notices` (чтобы письмо за 7 дней отправлялось один раз).

### 7.9 Лимиты, метеринг, retention

- Прокси считает секунды STT (стандарт/премиум), токены, запросы ассистента, задачи агентов → `usage_counters`; при превышении — предложение пакета 15 ч за $10 или апгрейда.
- Ежедневный cron: удалить просроченные резюме/расшифровки (кроме открытых обещаний); за 7 дней до удаления отправить письмо со ссылкой на скачивание (⚠ нужен транзакционный почтовый сервис с бесплатным уровнем).
- Экспорт: Markdown + JSON (PDF позже).

### 7.10 Инструментирование расходов (с первого дня)

Логировать на звонок/пользователя: секунды STT по провайдерам, токены in/out по задачам, число скриншотов, символы TTS, число карточек в час. Сверять с моделью из раздела 11; предупреждение, если расход пользователя превышает ~60% его цены.



## 8. Интеграции и индексация

- **Источники:** локальные папки; Gmail, Outlook (Microsoft Graph); Google Calendar/Outlook Calendar; Slack; Google Drive; Notion; Jira. Строим на **MCP**: готовых коннекторов много; Max/Ultra — свои MCP-коннекторы.
- **Доступ:** только чтение. OAuth с минимальными правами.
- **Индексация заранее**, не «вживую» (живой запрос к почте = 1–2 с): начальная загрузка за ограниченный период (⚠ последние N месяцев, настраивается), далее инкрементально; бриф перед звонком подгружает нужное в кэш.
- **Gmail:** ограниченные (restricted) права Google для публичного приложения требуют сторонней проверки безопасности (годовая стоимость от сотен до нескольких тысяч долларов, ⚠ проверить). На MVP — собственный проект Google Cloud в **тестовом режиме** (ограниченное число тестовых пользователей).
- **Не поддерживаем:** личные переписки Telegram/WhatsApp.
- **Solo:** 1 интеграция; **Pro:** все; **Max/Ultra:** все + свои MCP.
