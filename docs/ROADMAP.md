## 13. Дорожная карта (Windows; ⚠ оценки при вечерней работе, ориентировочные)

Порядок (решён): сначала **ядро курсора** (ближе всего к Clicky, быстрее даёт демо), затем прослушивание звонков.

**P0. Подготовка (1–2 дня).** Репозиторий, Electron+TS+Vite, линтер/тесты, CLAUDE.md и docs/, `packages/plans` (plans.ts + features-info.ts + тест на наличие `info`), обработка `.env`, аккаунты (Groq, Gemini, Supabase Free, Google Cloud test).
**P1. Ядро курсора (неделя 1).** Окна панели и оверлея; скриншот по клавише; запрос голосом/текстом → vision-LLM → JSON шагов → курсор 1→2→3; несколько мониторов и DPI; `setContentProtection`; определение активного окна. *Приёмка:* в Figma/Excel курсор ведёт к 3 элементам; панель не видна в демонстрации экрана (Zoom/Meet/Teams).
**P2. Звук и живая расшифровка (неделя 2).** Микрофон + loopback, VAD, STT (Groq/локальный), расшифровка «я/они» в панели; панель с настройкой угла. *Приёмка:* 10-минутный созвон → правильные каналы, задержка < 3 с.
**P3. Локальные знания (неделя 3).** Индексация папок, гибридный поиск, карточки с файлом/страницей. *Приёмка:* голосом «цифры по логистике за Q2» → находит файл и страницу.
**P4. Реакции (неделя 4).** Префильтр, классификатор, карточки L1, режимы, имена, горячая клавиша «помоги с последним», глоссарий, шёпот L2 в паузах (выбор устройства вывода, защита от петли), подтверждение голосом для L3, кнопка «не мне». *Приёмка:* эвал по записям (EN/RU/RO): доля ложных срабатываний L2/L3 ниже порога (⚠ задать), карточка ≤ 3 с.
**P5. После звонка (недели 5–6).** Резюме, трекер обещаний, история звонков, бриф перед звонком (календарь + локальные документы), память по приложениям (плашка, редактирование), наборы подсказок (Figma/Excel/Jira), кнопка «не сохранять».
**P6. Backend и оплата (недели 6–8).** Auth, схема+RLS, прокси+метеринг+лимиты, синхронизация текста, retention+письма за 7 дней, экспорт, Paddle (чекаут, триал, вебхуки), установщик + подпись, лендинг. **MVP для первых платящих = P1–P6 + Gmail из P7.**
**P7. Интеграции (недели 8–10).** Gmail (OAuth, тестовый режим), календарь, Slack, Drive, Notion, Jira, Outlook; инкрементальная индексация; свои MCP-коннекторы (Max+).
**P8. Ultra (недели 10–14).** Режим ассистента (текст в панели; курсор при необходимости), UI Automation + OCR, проверка шагов, «Не то?», тихий текстовый ввод в звонке, «сделать за вас» с подтверждением, фоновые агенты, запись/повтор процессов, обучающий режим, пакеты знаний.
**P9. macOS.** Порт (ScreenCaptureKit, разрешения, подпись/нотаризация ≈ $99/год).
**P10. Публичный запуск.** Лендинг+демо-видео, ToS/Privacy, DPA, проверка принятия Paddle, проверка Google (если нужна), мониторинг расходов.

**Проверка спроса (решение):** цены зафиксированы; интервью не проводим (спрашивать не у кого). После MVP: демо-видео (30–60 секунд, одна сцена: вопрос → карточка → курсор в Figma) + лендинг с тарифной таблицей и предзаказом по основательским условиям.



## 12. Как строить бесплатно (старт без вложений)

- **STT:** Groq Whisper (бесплатный уровень: 20 запросов/мин, 2 000/день, 7 200 секунд аудио в час — хватает для личного использования; для продакшена не годится) и/или локальный Whisper. Embeddings — локально (Ollama).
- **LLM:** бесплатные уровни Gemini/Groq (условия проверять) или локальный Ollama (Qwen).
- **Backend:** Supabase Free для разработки.
- **Google OAuth:** тестовый режим (свой проект Google Cloud).
- **Подпись приложения:** для личной разработки не нужна (предупреждения SmartScreen допустимы); перед публичным релизом — подпись (≈ $10/мес или $200–400/год, ⚠ проверить).
- **Платежи:** Paddle подключаем на этапе P6.
- **Прогон «только для меня»:** почти $0.



## 14. Тестирование и метрики

- Эвал-набор: записи звонков EN/RU/RO (в т. ч. смешанная речь), размеченные вопросы и адресаты; метрики: точность `is_question`, `addressed_to_me`, доля ложных L2/L3, задержка карточки.
- Тесты: юнит (триггеры, ретривер, лимиты, retention), интеграционные (пайплайн на записях), ручные сцены A–D (раздел 3), Figma-canvas.
- Расходы: сверка реальных расходов на час с моделью (7.10).
- Безопасность: проверки RLS, отсутствие ключей в клиенте, чёрный список окон, удаление данных.
